## 🗂️ IMPORTANT FILES & LOCATIONS

### Startup Commands
```bash
# Web UI
pnpm dev                          # Start web dev server (port 5175)

# API
pnpm api:dev                      # Start NestJS API (port 3001)

# Database
docker compose up -d              # Start PostgreSQL & Redis

# Mobile
cd apps/mobile
npm run build:ios / build:android

# Desktop
cd apps/desktop
npm run build:windows / build:macos / build:linux
```
